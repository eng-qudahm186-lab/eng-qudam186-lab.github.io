# Momen Al-Qudah Portfolio

This is a static two-page portfolio website for Momen Al-Qudah (SID 158600), a fourth-year Software Engineering student at Jordan University of Science and Technology.

## Files

- `index.html` — Home page
- `contact.html` — Contact Me page
- `style.css` — Responsive visual design
- `script.js` — Required form validation and success alert
- `momen-profile.jpg` — Momen's profile photo supplied for the assignment
- `manus-routes.json` — Page route manifest

## Before submission

The supplied profile photo is already connected in `index.html`. Keep `momen-profile.jpg` in the same folder when uploading the website.

To test the site locally, run `python3 -m http.server 3000` in this folder and open `http://localhost:3000`.
